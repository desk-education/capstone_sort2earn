Project Overview

Understanding the Smart Trash Bin

The Smart Trash Bin is an improved waste container designed to open and close its lid automatically. It uses a mechanical linkage system connected to an actuator that lifts and lowers the original lid of a standard plastic trash bin.

In this project, students will use larger plastic trash bins with their original lids. The mechanical parts will be installed to allow the lid to open and close when activated by the control system developed by the students.

The mechanical fabrication portion of the project focuses on the trash bin, hinges, mounting brackets, servo arm, connecting rod, and other mechanical components.

↕

Automatic Opening

The mechanism lifts the lid without requiring the user to manually open the trash bin.

↔

Automatic Closing

The mechanism returns the lid to its original closed position after activation.

⚙

Mechanical Linkage

The servo arm and connecting rod transfer motion to the hinged trash bin lid.

Recommended Mechanical Arrangement

How the servo transfers movement to the lid

⚙

Servo Motor

Provides controlled rotation.

→
↗

Servo Arm

Transfers movement from the servo shaft.

→
↔

Connecting Rod

Pushes or pulls the lid attachment.

→
↕

Trash Bin Lid

Opens and closes through the hinge.

Mechanical Operation

The servo motor rotates its shaft. The servo arm transfers the rotational movement to the connecting rod. The rod pushes or pulls the lid, causing it to rotate around the hinge.

When the servo returns to its original position, the connecting rod lowers the lid back to its closed position.

Design Reminder: The hinge must support the lid independently. Do not allow the servo shaft to carry the entire weight of the lid directly.

Step-by-Step Mechanical Fabrication

Simple preparation and assembly procedure

Fabrication Progress 0 / 10 Steps Completed
1

Prepare the Trash Bin

Prepare a clean, sturdy plastic trash bin with its original lid. Place it on a flat surface and make sure it is stable.

  • Check the body of the trash bin.
  • Inspect the lid for cracks.
  • Make sure the bin does not easily tip over.
2

Check the Lid and Hinge

Open and close the lid manually. Make sure the hinge is secure and the lid moves smoothly.

  • Tighten loose screws.
  • Remove obstructions.
  • Install a hinge if necessary.
3

Identify the Mounting Location

Identify a suitable location at the rear of the trash bin where the servo motor and mechanical linkage can be installed.

  • Avoid obstructing the bin opening.
  • Check the lid's movement path.
  • Mark the mounting position.
4

Install the Mounting Bracket

Attach the L-bracket to the rear of the trash bin using bolts, nuts, and washers.

  • Reinforce thin plastic areas.
  • Make sure the bracket is stable.
  • Avoid overtightening the bolts.
5

Mount the Servo Motor

Attach the servo motor to the mounting bracket and secure it using the appropriate mounting screws.

  • Check shaft clearance.
  • Ensure the servo is firmly mounted.
  • Prevent the motor from wobbling.
6

Attach the Servo Arm and Connecting Rod

Attach the servo arm to the motor shaft. Connect one end of the connecting rod to the servo arm using a pivot bolt.

  • Secure the arm properly.
  • Allow the rod to pivot.
  • Check for mechanical clearance.
7

Connect the Rod to the Lid

Attach the other end of the connecting rod to the trash bin lid using a small bracket and pivot bolt.

  • Choose a strong attachment point.
  • Reinforce the lid if necessary.
  • Make sure the connection is secure.
8

Adjust the Linkage

Adjust the connecting rod length and attachment positions so the lid can open and close without obstruction.

  • Check the opening movement.
  • Check the closing movement.
  • Prevent the linkage from locking.
9

Install the Rubber Bumper

Attach a small rubber bumper or foam pad to the lid's contact area to reduce impact and noise.

  • Position the bumper correctly.
  • Make sure the lid still closes.
  • Prevent excessive closing force.
10

Perform the Final Inspection

Inspect the entire mechanical assembly before integrating the students' electronic control system.

  • Check all bolts and nuts.
  • Check the bracket and linkage.
  • Ensure smooth lid movement.
  • Remove sharp edges.
  • Check the stability of the bin.

⚡ Precision Electrical Schematic & Pinout Reference

Includes standard electronic schematic symbols, exact component ratings (5V 5A DC, 1000µF 16V capacitor, 5A fuse), 1kΩ / 2kΩ Voltage Divider protecting ESP32 GPIO 4 from the HC-SR04 5V ECHO signal, and 2004 I2C LCD Display wiring.

🛡️ Critical Protection: Fixing HC-SR04 5V ECHO Output for 3.3V ESP32 VOLTAGE DIVIDER SOLUTION

The standard HC-SR04 requires 5V VCC to fire accurately, which causes its ECHO pin to output a 5.0V digital pulse. Because ESP32 GPIO pins are strictly 3.3V tolerant, connecting ECHO directly can damage GPIO 4. Solve this in 2 minutes using a simple two-resistor Voltage Divider (costs ₱2.00):

HC-SR04 ECHO (5.0V) ──[ R1 = 1kΩ ]──┬──▶ ESP32 GPIO 4 (Safe 3.33V)
                                     │
                                 [ R2 = 2kΩ ] (Formula: Vout = 5V × [2kΩ / (1kΩ + 2kΩ)] = 3.33V)
                                     │
                               COMMON GND

Note: The TRIG pin is an input on the HC-SR04 and reliably reads the ESP32's 3.3V HIGH pulse directly—no resistor needed on TRIG! (Alternative option: use an HC-SR04P or RCWL-1601 ultrasonic sensor rated for 3.3V–5V operation.)

/**
 * Sort2Earn Google Sheets Sync Receiver (Apps Script)
 * Automatically creates 3 tabs: Summary, Parts_Inventory, and Build_Checklist
 */
function doGet(e) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const summarySheet = ss.getSheetByName("Summary");
    const partsSheet = ss.getSheetByName("Parts_Inventory");
    const checkSheet = ss.getSheetByName("Build_Checklist");

    let teamName = "";
    if (summarySheet && summarySheet.getLastRow() >= 2) {
      teamName = String(summarySheet.getRange(2, 3).getValue() || "");
    }

    const inventory = [];
    if (partsSheet && partsSheet.getLastRow() >= 2) {
      const pRows = partsSheet.getDataRange().getValues();
      for (let i = 1; i < pRows.length; i++) {
        const actualQty = Number(pRows[i][4]);
        inventory.push({
          id: String(pRows[i][0] || ""),
          category: String(pRows[i][1] || ""),
          name: String(pRows[i][2] || ""),
          qty: String(pRows[i][3] || ""),
          actualQty: isNaN(actualQty) ? 0 : actualQty,
          condition: String(pRows[i][6] || "Good"),
          checked: String(pRows[i][7] || "").toUpperCase() === "YES"
        });
      }
    }

    const checklist = [];
    if (checkSheet && checkSheet.getLastRow() >= 2) {
      const cRows = checkSheet.getDataRange().getValues();
      for (let j = 1; j < cRows.length; j++) {
        checklist.push({
          id: String(cRows[j][0] || ""),
          phase: String(cRows[j][1] || ""),
          task: String(cRows[j][2] || ""),
          checked: String(cRows[j][3] || "").toUpperCase() === "COMPLETED"
        });
      }
    }

    return ContentService
      .createTextOutput(JSON.stringify({
        status: "success",
        teamName: teamName,
        inventory: inventory,
        checklist: checklist
      }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const ss = SpreadsheetApp.getActiveSpreadsheet();

    // 1. Update Summary Tab
    let summarySheet = ss.getSheetByName("Summary") || ss.insertSheet("Summary");
    summarySheet.clear();
    summarySheet.appendRow(["Timestamp", "School", "Team / Group Name", "Coach", "Research Paper Mentor", "Parts Ready", "Steps Done", "Completion %"]);
    summarySheet.appendRow([
      new Date().toLocaleString(),
      "Don Vicente Rama Memorial National High School",
      data.teamName || "Grade 12 STEM Team",
      "Mhuddy T. Dagatan",
      "Chona Reyes",
      data.partsSummary,
      data.stepsSummary,
      data.completionPercent + "%"
    ]);

    // 2. Update Parts Inventory Tab (Includes Required Qty, Available/Actual Qty, +/- Adjustment, and Good/Bad Condition)
    let partsSheet = ss.getSheetByName("Parts_Inventory") || ss.insertSheet("Parts_Inventory");
    const existingRows = partsSheet.getDataRange().getValues();
    const previousQtyMap = {};
    if (existingRows.length > 1) {
      for (let r = 1; r < existingRows.length; r++) {
        const rowId = String(existingRows[r][0] || "");
        const prevActual = Number(existingRows[r][4]);
        if (rowId && !isNaN(prevActual)) {
          previousQtyMap[rowId] = prevActual;
        }
      }
    }

    partsSheet.clear();
    partsSheet.appendRow([
      "ID",
      "Category",
      "Component / Material",
      "Required Qty",
      "Available / Actual Qty",
      "Net Change (+/-)",
      "Part Status (Good/Bad)",
      "Acquired?"
    ]);
    data.inventory.forEach(item => {
      const actualQty = typeof item.actualQty === "number" ? item.actualQty : (item.checked ? 1 : 0);
      const prevQty = previousQtyMap.hasOwnProperty(item.id) ? previousQtyMap[item.id] : actualQty;
      const netDelta = actualQty - prevQty;
      const deltaLabel = netDelta > 0 ? ("+" + netDelta) : String(netDelta);
      const condition = item.condition || "Good";
      partsSheet.appendRow([
        item.id,
        item.category,
        item.name,
        item.qty,
        actualQty,
        deltaLabel,
        condition,
        item.checked ? "YES" : "PENDING"
      ]);
    });

    // 3. Update Build Checklist Tab
    let checkSheet = ss.getSheetByName("Build_Checklist") || ss.insertSheet("Build_Checklist");
    checkSheet.clear();
    checkSheet.appendRow(["Step #", "Phase", "Task Description", "Status"]);
    data.checklist.forEach(step => {
      checkSheet.appendRow([step.id, step.phase, step.task, step.checked ? "COMPLETED" : "IN PROGRESS"]);
    });

    return ContentService
      .createTextOutput(JSON.stringify({ status: "success", message: "Synced to Google Sheets!" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
